Reversi Workshop Bot API

Use this Swagger UI for the external tournament bot endpoints. Bots typically register once, then poll for assignments roughly every {{ "%.2f"|format(recommended_poll_interval_seconds) }} seconds.

Each registered bot may send at most one authenticated request every {{ "%.2f"|format(external_bot_request_interval_seconds) }} seconds. Faster requests are rejected with 429 Too Many Requests, a Retry-After header, and a JSON retry_after_seconds field.

The operator can change that limit mid-tournament from the browser UI. Bots should therefore treat the current rate as dynamic, keep an eye on limit_seconds, and always honor Retry-After if they are throttled.

If a bot does not submit a move within {{ bot_turn_timeout_seconds }} seconds of its turn becoming active, the server forfeits that game.

Also available: bot instructions and the raw OpenAPI JSON.
